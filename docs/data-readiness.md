# Матрица готовности данных

**Версия:** 1.1 · **Дата проверки:** 2026-09-27 · **Итог:** `data: BLOCKED_DATA`
**История:** 1.0 (commit 9d4ebc2) — первичная. 1.1 — по рецензии `CERES_PREFLIGHT_REVIEW_v1.0` §8:
точные хосты и пути загрузки, поля по каждому обязательному источнику, разделение
свидетельств по силе, требование к поставке EOD (`docs/eod-delivery-requirements.md`),
запрос сетевого доступа под текущую стадию (`docs/network-access-request.md`).

## 1. Уровни свидетельств

Чтобы не выдавать недоступность хоста за отсутствие архива и архивную карточку — за
PIT-датасет, свидетельства разделены по силе:

| Уровень | Смысл |
|---|---|
| **E0** — не проверено | Нет никакого свидетельства, кроме текста v0.2 |
| **E1** — поисковый индекс | URL/заголовок найдены веб-поиском; файл исполнителем **не загружен**, содержимое не проверено |
| **E2** — карточка проверена рецензентом | Рецензент открыл публичную страницу выпуска (сообщено в рецензии); исполнитель не воспроизвёл |
| **E3** — образец загружен и разобран | Исполнитель загрузил файл, сохранил raw hash, разобрал нужные поля |
| **E4** — PIT-датасет принят | Полнота выпусков, первоначальные версии и исправления проверены, датасет принят аудитором |

**На 2026-09-27 ни один источник не достиг E3.**

| Хост | Способ | Результат |
|---|---|---|
| `esmis.nal.usda.gov` | curl и WebFetch | отклонено egress-политикой окружения (`connect_rejected` / `EGRESS_BLOCKED`) |
| `www.usda.gov`, `quickstats.nass.usda.gov`, `apps.fas.usda.gov`, `usda.library.cornell.edu`, `www.cftc.gov`, `www.ncei.noaa.gov`, `api.eia.gov`, `www.cmegroup.com`, `arxiv.org` | curl | отклонено egress-политикой окружения |

**Недоступность хоста из этой среды не означает отсутствия архива.** Это операционное
ограничение среды, а не свойство источника.

## 5. Пригодная научная история

Пригодная история определяется **совместной** доступностью: (а) EOD settlement
индивидуальных контрактов; (б) PIT-признака WASDE (для B1 — шесть MY из одного
vintage, т.е. +5 лет до первого пригодного года, ADR-09); (в) метаданных лимитов,
календаря, FND/LTD. Сейчас ни один компонент не подтверждён на уровне E3, поэтому
число пригодных лет **не может быть указано**. Двадцать лет современных
пересмотренных таблиц не являются PIT-историей.
