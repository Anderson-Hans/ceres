# ADR-01. B0, событие B1, оболочка распределения B1 и сравнение B2 с B1

**Статус:** Proposed
**Дата:** 2026-09-27
**Затрагивает:** §3, §4, §7.2, §9 (фазы 1–2), §10 спецификации v0.2
**Тип:** [ADR] — формализация пробела. Ничто ниже не является дословным требованием v0.2.

## Контекст

v0.2 задаёт B0 как «климатология + случайное блуждание» (§3), B1 как
«P(сезонный паттерн отработает | дециль отклонения запасов от 5-летнего
среднего)» (§3), гейт фазы 1 — «B1 бьёт B0 по Brier» (§9), гейт фазы 2 —
«B2 бьёт B1» (§9), основную метрику — CRPS (§7.2, §10). Не определены:

1. единственная формула B0 и его предиктивное распределение;
2. бинарная метка «сезонный паттерн отработал», правила знака и нуля;
3. связь события B1 с `p_up`;
4. распределение величины доходности у B1 — без него «B2 бьёт B1» по CRPS
   не определено (Beta-Binomial даёт распределение бинарного исхода, а
   CRPS бинарной переменной равен Brier и не является CRPS доходности).

## Решение (предлагаемое)

### 1. Обозначения

- Сезонная позиция `s(t)` — номер торгового дня внутри окна пригодности
  контракта (ADR-06), выровненный по агрономическому календарю.
- Сезонное окно `W(s) = {s' : |s' − s| ≤ k}`, `k = 10` торговых дней
  (диапазон для чувствительности: `{5, 10, 15}`, основной — 10, выбран до OOS).
- `R(t,H)` — наблюдаемая settlement-доходность (ADR-02).
- Все оценки ниже — только по training-меткам, конец горизонта которых
  не позже cutoff фолда (ADR-05).

### 2. B0 — основной baseline (единственный для гейтов)

**B0 = «случайное блуждание по положению, климатология по масштабу и форме».**

`F_B0(r) = F̂_train( r + m̂ | культура, H, W(s) )`,

где `F̂_train` — взвешенное эмпирическое распределение training-доходностей
той же культуры и горизонта в сезонном окне, `m̂` — его медиана. То есть
распределение сдвигается так, чтобы медиана была нулевой (нет
предсказуемого направления — случайное блуждание), а ширина и форма
хвостов берутся из климатологии этой сезонной позиции.

`p_up(B0) = 1 − F_B0(0)` (строгое `>`; атом в нуле относится к «не вверх»).

Отдельно хранятся и публикуются в отчётах, **но не используются в гейтах**:

- `B0-CLIM`: `F̂_train(r | культура, H, W(s))` без центрирования
  (чистая сезонная климатология, включая климатологическое направление);
- `B0-RW`: `N(0, H·σ̂²_t)`, где `σ̂_t` — стандартное отклонение дневных
  лог-доходностей того же контракта за 63 торговых дня до `t` (только
  внутриконтрактные доходности, без ролла).

**Почему не смесь.** Веса смеси CLIM/RW были бы ещё одним свободным
параметром, который соблазнительно выбрать по результату. Основной B0
выбран один, заранее. Раскрытие skill относительно B0-CLIM и B0-RW
обязательно (чтобы аудитор видел, не «слабый ли» выбран baseline).

**Вопрос аудитору (открыт):** B0-RW с актуальной волатильностью может
оказаться сильнее основного B0. Требовать ли для §10 положительный skill
против *сильнейшего* из трёх вариантов? Рекомендация исполнителя: гейт —
только против основного B0 (как в v0.2, B0 один), но если skill против
B0-RW ≤ 0, это выносится в отчёт как существенное ограничение.

### 3. Событие B1

Сезонное направление (сезонный априор) на training:

`d(c, H, s) = sign( median F̂_train(r | c, H, W(s)) )`, при медиане, равной
нулю, `d = +1` (детерминированный tie-break; частота таких случаев
раскрывается).

Событие: `E(t,H) = 1`, если `d · R(t,H) > 0`; иначе `E = 0`.
Нулевая доходность (`R = 0`, возможна из-за дискретного шага цены) —
`E = 0` («паттерн не отработал»).

Связь с `p_up`. Для всех моделей `p_up = P(R > 0) = 1 − F(0)` из
предиктивного распределения. Для оболочки B1 (п. 5):

- `d = +1`: `E = 1 ⇔ R > 0`, поэтому `p_up = p_E`;
- `d = −1`: `E = 1 ⇔ R < 0`, а класс `E = 0` содержит и `R > 0`, и `R = 0`,
  поэтому `p_up = (1 − p_E) · (1 − π0)`, где `π0` — training-доля нулей в
  классе `E = 0` (а не `1 − p_E`).

Гейт фазы 1 (Brier) оценивает вероятность события `E` — одинакового для
B0 и B1; у B0 `P(E)` вычисляется из `F_B0` тем же правилом.

### 4. Beta-Binomial

Группы: культура × горизонт × дециль признака `x` (ADR-09).
Границы децилей — по training (значения признака на training-датах,
по одной точке на каждый опубликованный vintage, без дублирования по
дням; ADR-09). Приор `Beta(a0, b0)`, основной вариант `a0 = b0 = 1`,
чувствительность `{0.5, 2}`.

Апостериорная предиктивная вероятность события:
`p_E = (a0 + k_w) / (a0 + b0 + n_w)`,
где `k_w = Σ w_i E_i`, `n_w = Σ w_i` — взвешенные счётчики (ADR-05):

- поправка на перекрытие горизонтов: `w_i ∝ 1/H` на строку (метки на
  соседних днях делят H−1 из H дневных доходностей);
- экспоненциальное дисконтирование лет с полужизнью из ADR-05.

Дробные веса делают это **степенным (power-prior) взвешенным
правдоподобием**, а не обычной биномиальной моделью с целыми
счётчиками. Это оговаривается явно в отчёте; `n_w` не выдаётся за число
независимых наблюдений.

Пустой дециль (`n_w = 0`): `p_E` = предиктивная вероятность пула той же
культуры и горизонта без разбиения на децили (не приор `0.5`); если пуст
и пул — ABSTAIN с `abstain_reason = "B1_EMPTY_CLASS"` (без выдуманной
вероятности). Отсутствие одного класса (все `E = 1` или все `E = 0`) —
обрабатывается приором штатно, без спецобработки.

**Обязательная диагностика (не гейт v0.2, рекомендуется сделать гейтом):**
`B1-pooled` — та же модель без децилей. Если B1 не лучше B1-pooled, то
прохождение гейта «B1 бьёт B0» объясняется сезонной климатологией
направления, а не связкой «запасы → отработка сезонности», и гипотеза
фазы 1 по существу не подтверждена. Рекомендация аудитору — включить
`Brier(B1) < Brier(B1-pooled)` в гейт фазы 1.

### 5. Оболочка полного распределения B1 (для CRPS и сравнения с B2)

`F_B1(r) = p_E · F̂_train(r | E=1, c, H, W(s)) + (1 − p_E) · F̂_train(r | E=0, c, H, W(s))`.

- `p_E` — апостериорная предиктивная (проинтегрированная) вероятность из
  п. 4, не точечная оценка случайного параметра.
- Условные распределения — эмпирические, только training, с весами
  ADR-05; поддержка — наблюдённые training-доходности (атомы допускаются;
  CRPS считается точно, `ceres.eval.crps.crps_empirical`).
- `R = 0` принадлежит классу `E = 0` (согласно п. 3).
- Пустой условный класс в окне `W(s)` → каскад: расширение окна до
  `k = 21` → пул всех сезонных позиций той же культуры и горизонта →
  ABSTAIN `B1_EMPTY_CLASS`. Каскад фиксирован до OOS; частота каждого
  шага раскрывается.

Это **дополнение к B1**, а не свойство Beta-Binomial.

### 6. Критерий «B2 бьёт B1» (гейт фазы 2, п. 1)

- Основной: `mean_w CRPS(B2) < mean_w CRPS(B1-оболочка)` на общем
  OOS-наборе целей (одинаковые `(t, instrument, H)`), с теми же весами,
  что и §10 (ADR-05). Раскрываются разница и блочный 95% ДИ.
- Вторичный: Brier по событию `E` (одинаковое событие у обеих моделей;
  у B2 `P(E)` вычисляется из её предиктивного распределения).
- Статистическая значимость для «B2 бьёт B1» не требуется (в v0.2 её
  нет); значимость требуется только в §10 (против B0). Вопрос аудитору:
  достаточно ли точечного превосходства.

Если оболочка B1 будет отвергнута аудитором, альтернатива должна быть
другим явным ADR; молча заменять «B2 лучше B1» сравнением только с B0
запрещено.

## Последствия

- Все модели сравниваются на одной и той же наблюдаемой величине.
- Гейт фазы 1 может быть пройден за счёт климатологии направления —
  это явно выявляется диагностикой B1-pooled.
- С 10 training-годами децили вырождаются (≈1 год на дециль) — см.
  spec-audit.md, риск R-04; предложение укрупнения требует решения
  аудитора, т.к. децили заданы v0.2.
