# ADR-07. Представление предиктивного распределения и запрос уровня L

**Статус:** Proposed
**Дата:** 2026-09-27
**Затрагивает:** §1, §4 спецификации v0.2; §11.3 execution-промпта
**Тип:** [EXEC/ADR] — интерфейсное дополнение, не новая модель

## Контекст

§1 формулирует вопрос как вероятность цены выше/ниже уровня L; запись
§4 содержит только `p_up` и пять квантилей — этого недостаточно для
произвольного L.

## Решение (предлагаемое)

1. Каждая модель сохраняет достаточное представление предиктивного
   распределения `R(t,H)` в sidecar-файле записи:
   - B0/B1: взвешенные атомы эмпирического распределения (значения и веса);
   - B2+: выборка posterior predictive (фиксированное число draw, seed).
2. Чистая функция `prob_level(dist, S0, L, op)`, `op ∈ {">", ">=", "<", "<="}`:
   - `P(S_H > L) = 1 − F_R(log(L/S0))`;
   - `P(S_H ≥ L) = 1 − F_R(log(L/S0)⁻)` (левый предел при атомах);
   - `P(S_H < L) = F_R(log(L/S0)⁻)`; `P(S_H ≤ L) = F_R(log(L/S0))`.
   - `S0 > 0`, `L > 0`, иначе ошибка.
3. `S0` — определённая reference-цена: settlement того же контракта в
   сессии `t` с timestamp, единицами (центы/бушель) и lineage; это не
   текущая исполнимая котировка.
4. Интерполяция пяти квантилей для восстановления CDF запрещена.
5. Вероятность касания уровня внутри H не вычисляется — динамика пути в
   v0.2 не задана.
6. Функция и тесты допускаются с фазы 1; внешний интерфейс — не
   раньше фазы 4 (односторонний экспорт).
