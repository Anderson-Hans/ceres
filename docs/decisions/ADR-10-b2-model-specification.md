# ADR-10. Спецификация модели B2 (фаза 2)

**Статус:** Proposed
**Версия:** 1.0 (2026-09-27)
**История:** 1.0 — создан по требованию рецензии `CERES_PREFLIGHT_REVIEW_v1.0` §6 (пробел G-14).
**Затрагивает:** §3 (B2), §2.5, §7.1, §9 (фаза 2) спецификации v0.2
**Тип:** [ADR] — v0.2 задаёт только класс модели («иерархическая логистическая/нормальная
регрессия с частичным пулингом по культурам и годам», NumPyro/NUTS). Всё ниже —
формализация исполнителя.
**Машиночитаемая версия:** `configs/model-b2.yaml` (при расхождении приоритет у этого ADR;
расхождение — дефект, проверяется тестом `tests/unit/test_model_b2_config.py`).

## 1. Проверяемая гипотеза

B2 проверяет, что **иерархическая непрерывная модель с частичным пулингом по культурам и
годам** на **том же информационном наборе, что и B1** (признак запасов ADR-09 и сезонная
климатология training), даёт лучшее предиктивное распределение доходности, чем
оболочка B1 (гейт «B2 бьёт B1», ADR-01 п.6) и чем B0 (§10).

Не входят в B2: NOAA, COT, Export Sales, Crop Progress, Grain Stocks, реализованная
волатильность, спреды, OI, любые признаки фаз 3+. Добавление любого признака — новая
версия спецификации и новая предрегистрация.

## 2. Единица наблюдения и выборка

- Строка = (культура `c`, горизонт `H`, торговая дата `t`), target `R(t,H)` по ADR-02,
  окно пригодности контракта ADR-06, срез `as_of_t` ADR-03.
- **Отдельная модель на каждый горизонт** `H ∈ {5, 21}` с одинаковой структурой;
  совместное моделирование горизонтов не проводится (перекрытие H=5 внутри H=21 не
  моделируется явно).
- Training-строки: конец горизонта и публикация settlement ≤ cutoff (ADR-05 п.5).
- Перекрытие меток: **композитное (взвешенное) правдоподобие**, вес строки `1/H`.
  Это псевдоправдоподобие; апостериорная неопределённость не является точной и
  проверяется posterior predictive checks и OOS-coverage. Чувствительность (раскрывается):
  неперекрывающиеся метки `t ≡ 0 (mod H)` в сессиях окна пригодности, вес 1.
- Строки без определённого признака `x` (нет 5 предыдущих MY, ADR-09) в training не
  входят; в OOS такие строки получают прогноз B0 (fallback, ADR-05 п.1) с
  `abstain_reason = "B2_FEATURE_UNDEFINED"`; доля раскрывается.

## 3. Признаки и преобразования (все — только по training фолда)

| Символ | Определение | Единицы | Vintage / лаг |
|---|---|---|---|
| `σ_c(s)` | Стандартное отклонение дневных внутриконтрактных лог-доходностей культуры `c` в сезонном окне `W(s)` (±10 сессий), по training-годам, с весами дисконтирования | лог-доходность/сессия | только цены, видимые в training |
| `m_c(H,s)` | Медиана training-распределения `R` в `W(s)` (центр B0-CLIM, ADR-01) | лог-доходность | training |
| `m̃` | `m_c(H,s) / (√H · σ_c(s))` | безразмерная | training |
| `x` | Отклонение stocks-to-use от 5-летнего среднего, все значения из vintage `v_t` (ADR-09) | пункты SU (доля) | последний WASDE с `vintage_time ≤ as_of_t`; дополнительного лага нет |
| `x̃` | `(x − mean_train(x_c)) / sd_train(x_c)`; среднее и sd — по одной точке на релиз WASDE, раздельно по культуре | безразмерная | параметры стандартизации — только training |
| `u` | `R(t,H) / (√H · σ_c(s))` | безразмерная | — |
| `post_c(t)` | Индикатор режима: 1 для ZW при `t ≥ 2022-02-24` | {0,1} | дата события, PIT-допустима |

Сезонное выравнивание — агрономическая координата `s(t)` (ADR-06).

## 4. Модель (для каждого H отдельно)

Индексы: культура `c ∈ {ZC, ZS, ZW}`, маркетинговый год `y`.

**Среднее:**
`η = a_c + a_{c,y} + b_c·x̃ + g_c·m̃ + q_c·x̃·m̃ + 1[c=ZW]·post·δ_a`

**Масштаб:**
`log σ_u = ς_c + ς_{c,y} + 1[c=ZW]·post·δ_ς`

**Правдоподобие:** `u ~ StudentT(ν, η, σ_u)`, поддержка — вся вещественная прямая
(лог-доходность; ограничения цены не моделируются, кроме цензурирования п.6).

**Частичный пулинг** (нецентрированная параметризация):
- по культурам: `a_c ~ N(a0, τ_a)`, `b_c ~ N(b0, τ_b)`, `g_c ~ N(g0, τ_g)`,
  `q_c ~ N(q0, τ_q)`, `ς_c ~ N(ς0, τ_ς)`;
- по годам (внутри культуры): `a_{c,y} ~ N(0, τ_y)`, `ς_{c,y} ~ N(0, τ_{ςy})`.

**Приоры (диапазоны фиксируются сейчас, §10 v0.2):**

| Параметр | Приор | Чувствительность |
|---|---|---|
| `a0` | N(0, 0.2) | — |
| `b0`, `q0` | N(0, 0.2) | — |
| `g0` | N(0, 0.5) | — |
| `ς0` | N(0, 0.5) | — |
| `τ_a`, `τ_b`, `τ_q` | HalfNormal(0.1) | масштаб ×2 |
| `τ_g`, `τ_ς`, `τ_{ςy}` | HalfNormal(0.2) | масштаб ×2 |
| `τ_y` | HalfNormal(0.3) | масштаб ×2 |
| `δ_a` | N(0, 0.5) | — |
| `δ_ς` | N(0, 0.5) | — |
| `ν` | 2 + Gamma(2, 0.1) | — |

Перебор приоров до улучшения метрики запрещён; чувствительность — единственный
зарегистрированный вариант, результаты раскрываются, гейт — только основной вариант.

## 5. Новый год и прогноз

- Для OOS-года `y*` эффекты `a_{c,y*}`, `ς_{c,y*}` **не оцениваются по его исходам**:
  в каждой апостериорной выборке они генерируются из `N(0, τ_y)` и `N(0, τ_{ςy})`.
  Переобучение внутри тестового года не проводится (ADR-05 п.5).
- Предиктивное распределение: для каждого draw `u* ~ StudentT(ν, η*, σ_u*)`,
  `R* = u*·√H·σ_c(s)`. 4 цепи × 1000 draw после 1000 warmup, `target_accept_prob=0.9`,
  seed из конфигурации. Draw сохраняются (ADR-07).
- `p_up = доля R* > 0`; квантили 0.05…0.95 — эмпирические по draw.

## 6. Лимитные дни (согласование с ADR-02)

- **Наблюдаемая величина** — settlement-доходность `R`; **скрытая** — `R*` (п.1 ADR-02).
- Цензурирование — **только конечной точки** `t+H`: `limit_state(t+H)=up` → вклад
  `log(1 − F_t((u_obs − η)/σ_u; ν))`; `down` → `log F_t(·)`; вес строки `1/H` сохраняется.
  Лимитность внутренних сессий горизонта и начальной точки цензурированием не является.
- Строки с `limit_state(t+H) = unknown` из training B2 исключаются (раскрывается доля);
  это не трактуется как «лимита не было».
- **Scoring на H=5 и H=21:** CRPS по наблюдаемому `R`, предиктивное распределение —
  `R*` без клиппинга (ADR-02 п.6), с обязательным срезом без лимитных конечных точек
  и порогом пересмотра 1% OOS-меток.

## 7. Дисконтирование

Вес строки года `a` при cutoff `T`: `(1/H)·λ^{T−a}`, `λ = 2^{−1/h}`. Полужизнь `h`
выбирается **во внутренних фолдах training** по сетке `{2, 4, 8, 16, ∞}` лет
(критерий — средний CRPS внутреннего фолда). Совместная оценка `h` в
взвешенном правдоподобии не используется: при весах, зависящих от параметра,
такое правдоподобие некорректно (изменяет суммарный вес данных). Это изменение
относительно ADR-05 v1.0 (где для B2 предлагался приор на `log h`).

Внутренние фолды — **прямые (forward-chaining)**: последние `min(5, n_train − 5)`
training-лет по очереди служат валидацией, обучение — на годах строго раньше.

## 8. ZW

- ZW входит в иерархию с индикатором режима `post` для среднего и масштаба; гейтовый
  вес 0; SIGNAL не публикуется (`INSTRUMENT_ROLE_STRESS_TEST`).
- Обязательная чувствительность: B2 без ZW (иерархия из двух культур). Если она лучше
  по CRPS на ZC/ZS — это раскрывается как основание исключить ZW из иерархии v2
  (не v1 — изменение после просмотра OOS не допускается).

## 9. Диагностика и публикация

`r_hat < 1.01` (v0.2); bulk/tail ESS ≥ 400 и 0 divergences — предложение ADR-03, не
требование v0.2. Проверяемые параметры: все гиперпараметры, `ν`, `δ_a`, `δ_ς`,
предиктивные `p_up` и квантили каждой прогнозной даты. Провал → ABSTAIN
`MCMC_DIAGNOSTICS_FAILED`, распределение сохраняется как исследовательское; для
основного CRPS используется это же распределение (полная выборка), а провал
раскрывается.

Posterior predictive checks (на training): распределение `u` по культурам и
сезонным окнам, доля хвостовых событий |u| > 3, coverage 50/90% на внутренних фолдах.

## 10. Что B2 не учитывает (ограничения)

- Совместная динамика горизонтов и межкультурная корреляция остатков не моделируются
  (учитываются только в блочном ДИ, ADR-05).
- Композитное правдоподобие занижает/завышает апостериорную неопределённость;
  калибровка проверяется только эмпирически.
- С тремя культурами оценка `τ` по культурам слабо идентифицируема — поэтому
  приоры информативны; результат по пулингу культур интерпретируется осторожно.
