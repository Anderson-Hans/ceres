# ADR-05. Проверка гипотезы, агрегирование, зависимость наблюдений и воспроизводимость

**Статус:** Proposed
**Версия:** 1.1 (2026-09-27)
**История:** 1.0 — первичная версия (commit 9d4ebc2): основной ДИ — jackknife-t по годам,
обоснование — упрощённая симуляция с моделью-оракулом. 1.1 — по рецензии
`CERES_PREFLIGHT_REVIEW_v1.0` §1–3: формулировки о «вероятном закрытии» и «верхней
границе» заменены условными по сценариям; ДИ определён полностью (блоки, парность,
ledger без переобучения, центрирование, df, малое число блоков); проведено
симуляционное исследование с нулевым сигналом, оцениваемыми параметрами, AR между
годами и тяжёлыми хвостами; критерии допустимости зарегистрированы до запуска;
по ним основным кандидатом стал JK2 (пары соседних лет), JK — вторичным; внутренние
фолды — прямые; полужизнь B2 — сетка во внутренних фолдах.
**Затрагивает:** §2.2, §7.1, §7.2, §10, §12 (вопросы 1, 2, 4, 5), §13 спецификации v0.2
**Тип:** [ADR]

## Контекст

§10: «если после фазы 2 skill score относительно B0 не положителен с 95% доверительным
интервалом, не пересекающим ноль, — проект закрывается». Не заданы метрика skill,
агрегирование, вес ZW, метод ДИ, учёт зависимости, пропуски, множественные сравнения.

## 1. Основная величина (стоп-критерий §10 не ослабляется)

`skill_CRPS = 1 − Σ w·CRPS(B2) / Σ w·CRPS(B0)` — **отношение взвешенных средних**, не
среднее индивидуальных skill score. Решение: `lower_bound(two_sided_CI_95(skill_CRPS)) > 0`.
Двусторонний 95% интервал не заменяется односторонней границей.

Веса `w = w_instr · w_H / n(instr, H)`: ZC 0.5, ZS 0.5, **ZW 0** (п.3); H=5 — 0.5,
H=21 — 0.5; внутри ячейки `(instr, H)` — равный вес на каждую пригодную OOS-дату.
Горизонт, культура, период после результата не выбираются: гейт — только агрегат.

Отсутствие прогноза у сравниваемой модели на пригодной цели не исключает строку:
используется зарегистрированный fallback (для B2 — B0), доля раскрывается. ABSTAIN не
исключает строку. Неопределённый знаменатель, недостаток честных данных или число
блоков меньше допустимого минимума метода (п.2.6) → `NOT_EVALUABLE`, что **не является**
положительным результатом.

## 2. Доверительный интервал

### 2.1 Блоки неопределённости

Блок = **календарный период 1 сентября – 31 августа**, общий для всех культур и обоих
горизонтов. Он не совпадает с маркетинговыми годами walk-forward (ZW — с 1 июня): блоки
неопределённости и фолды — разные элементы методики (ADR-06 п.2a). Строка относится к
блоку по дате отсчёта `t`. Разные названия маркетинговых лет не разрывают совместные
шоки: ZC, ZS и ZW одной даты всегда в одном блоке.

### 2.2 Парность

Обе модели оцениваются на одном и том же множестве строк `(t, instr, H)` с одинаковыми
весами; процедуры удаляют/переоценивают блоки для обеих моделей одновременно.

### 2.3 Что удаляется и какие источники неопределённости учтены

Все процедуры работают с **уже причинно построенным OOS-ledger**: удаляются или
переоцениваются блоки строк ledger, **модели не переобучаются**. Учитывается:
выборочная изменчивость OOS-периода при фиксированных подогнанных моделях, включая
зависимость внутри блока (перекрытие горизонтов, межкультурные шоки, общий режим
волатильности года). **Не учитывается:** неопределённость обучения (другие training-данные
дали бы другие модели), неопределённость выбора гиперпараметров во внутренних фолдах,
зависимость между блоками сверх той, что поглощают парные блоки (JK2). Estimand —
skill подогнанных моделей на процессе, порождающем OOS-период.

### 2.4 Кандидаты (точные определения)

Обозначения: `k` — число блоков; `M_j = Σ_{i∈j} w_i·CRPS_i(B2)`, `R_j` — то же для B0;
`θ̂ = 1 − ΣM_j / ΣR_j`.

- **JK2 (основной кандидат):** delete-one-block jackknife, где блок — **пара соседних
  календарных периодов** (годы 1–2, 3–4, …; при нечётном `k` последний блок — одиночный
  год). `k₂ = ⌈k/2⌉`. `θ̂_(−b) = 1 − (ΣM − M_b)/(ΣR − R_b)` (отношение пересчитывается
  целиком). `SE = sqrt((k₂−1)/k₂ · Σ_b (θ̂_(−b) − mean_b θ̂_(−b))²)`. Интервал центрирован в
  `θ̂` (без поправки на смещение): `θ̂ ± t_{0.975, k₂−1}·SE`. Требует `k₂ ≥ 3`.
- **JK:** то же с блоком = один календарный период, `t_{0.975, k−1}`.
- **PB:** парная перцентильная переоценка блоков-лет: `k` блоков с возвращением,
  `θ* = 1 − ΣM*/ΣR*`, интервал — 2.5% и 97.5% квантили `θ*`; `n_resamples = 10000` в
  регистрации (2000 в симуляционном исследовании), seed фиксирован.
- **Запрещено:** любые процедуры, считающие дневные строки независимыми (в исследовании
  — `IID`, дельта-метод по строкам, только как демонстрация дефекта).

### 2.5 Малое число блоков, соседние годы, влиятельные годы

- Минимум блоков — п.2.6; при меньшем числе — `NOT_EVALUABLE`.
- Чувствительность к зависимости соседних лет: сравнение JK (одиночные годы) и JK2
  (пары) раскрывается всегда.
- Влиятельные годы: публикуются `θ̂_(−j)` для каждого одиночного года; если исключение
  одного года меняет знак нижней границы основного ДИ, это раскрывается как существенное
  ограничение (решение гейта не меняет).

### 2.6 Критерии допустимости метода (зарегистрированы в коде до запуска исследования)

`src/ceres/preflight/simstudy.py::admissibility`. Для всех зарегистрированных сценариев
при `k ≥ 10` OOS-лет:

- **(A)** односторонняя ошибка нижней границы `P(lower > истинный skill)` ≤
  `0.025 + 2·sqrt(0.025·0.975/n)` (n — число повторений; для n=2000 порог 0.0320, для
  n=1000 — 0.0349). В нулевых сценариях с истинным skill = 0 это частота ложного
  прохождения гейта. **Допустимость для гейта определяется по (A).**
- **(B)** покрытие двустороннего интервала ≥ `0.95 − 2·sqrt(0.95·0.05/n)`; раскрывается как
  качество двустороннего интервала.

Метод выбирается по этим критериям до открытия OOS и **не** по тому, пропускает ли он
CERES на реальном OOS.

### 2.7 Результаты симуляционного исследования (синтетика, `is_synthetic: true`)

Пакет: `artifacts/preflight-r2-2026-09-27/synthetic/simstudy/` (код, метаданные,
все повторения, сводка, допустимость, лог). 100 ячеек: 8 сценариев × целевые skill ×
OOS-лет {6, 10, 15, 20, 30}; 2000 повторений в нулевых ячейках, 1000 — в прочих.
Результаты относятся только к заданному DGP (описание — в модуле и в
`simstudy-summary.md`).

| Метод | (A) нижняя граница, k ≥ 10 | Ложное прохождение в нулевых сценариях с skill=0 (k ≥ 10) | (B) покрытие |
|---|---|---|---|
| JK2 | **PASS** (0 нарушений) | 0.018–0.028 | FAIL: 0.896–0.960; недопокрытие — в сценариях с skill > 0, преимущественно за счёт верхней границы |
| JK | FAIL (2 пограничных нарушения: 0.0345 при пороге 0.032 в `S0_null_est`, k=15; 0.0325 при 0.032 в `S0_null_exch_heavy`, k=30) | 0.013–0.033 | FAIL: 0.88–0.97 |
| PB | FAIL (26 нарушений) | 0.027–0.056 | FAIL: 0.83–0.94 |
| IID (запрещён) | FAIL | 0.36–0.40 | FAIL: 0.13–0.28 |

**Решение (предлагаемое):** основной метод — **JK2**; JK и PB — раскрываемые
чувствительности. Нарушения JK пограничны и сопоставимы с ошибкой Монте-Карло; по
зарегистрированному правилу он всё же не допущен. Минимальное число блоков: JK2
допущен при `k ≥ 10` (при k = 6 критерий не применялся; там ошибка нижней границы
JK2 ≤ 0.028, но это вне зарегистрированной области) → **при k < 10 результат §10 —
`NOT_EVALUABLE`**.

**Ограничение, которое раскрывается:** ни один метод не проходит (B). При skill > 0
верхняя граница всех методов систематически занижена (распределение оценки
отношения асимметрично), поэтому верхний конец двустороннего интервала нельзя
интерпретировать как 97.5%-границу. Решение гейта зависит только от нижней границы,
для которой (A) выполнено. Улучшение верхней границы (например, студентизированная
переоценка) — отдельное предложение, если аудитор сочтёт нужным до OOS.

### 2.8 Вероятность прохождения §10 внутри DGP (не прогноз для рынка)

Метод JK2, двусторонний 95% ДИ, в таблице — частота `lower > 0` (MCSE ≤ 0.016):

| Сценарий (DGP) | истинный skill | 10 лет | 15 лет | 20 лет | 30 лет |
|---|---:|---:|---:|---:|---:|
| S1 оракул (известный дрейф) | 0.01 | 0.078 | 0.138 | 0.210 | 0.328 |
| S1 оракул | 0.02 | 0.130 | 0.255 | 0.323 | 0.527 |
| S1 оракул | 0.03 | 0.153 | 0.338 | 0.479 | 0.718 |
| S2 признак corr 0.7, параметры по 10 годам | ≈0.017 | 0.104 | 0.187 | 0.294 | 0.456 |
| S2 | ≈0.026 | 0.130 | 0.259 | 0.344 | 0.545 |
| S3 как S2 + AR(0.5) между годами | ≈0.016 | 0.093 | 0.201 | 0.276 | 0.409 |
| S4 признак corr 0.7, t4-шоки, неоднородные годы | ≈0.020 | 0.105 | 0.174 | 0.270 | 0.396 |

Интерпретация без обобщения на рынок: **внутри этого DGP** при 10–15 OOS-годах и
истинном skill 1–3% гейт §10 проходится в 8–34% повторений. Оракул — ориентир внутри
DGP (модель знает истинный дрейф), а не доказанная верхняя граница вероятности на
рынке: другой DGP (иная зависимость, иной вид сигнала) может дать и большую, и
меньшую вероятность.

Разделяются три вещи: (1) наличие сигнала в DGP; (2) вероятность обнаружить его
выбранным экспериментом (таблица выше); (3) фактический результат CERES на реальных
данных — **не получен**, реальный научный гейт не запускался, вердикт `STOP_SCIENCE`
не установлен. После корректного реального эксперимента непрохождение §10 означает
остановку по установленному правилу; оно не доказывает отсутствие любого возможного
рыночного сигнала.

## 3. ZW

ZW (роль — стресс-тест режимного слоя, §2.2) имеет `gate_weight = 0`; SIGNAL по ZW в
v1 не публикуется (`INSTRUMENT_ROLE_STRESS_TEST`). В B2 ZW участвует с индикатором
режима `post` (ADR-10 п.8); чувствительность — B2 без ZW. Вопрос аудитору (OI-07):
допустима ли интерпретация «пониженного веса» §2.2 как веса 0 в гейте.

## 4. Множественные сравнения и отбор

- Одна основная конечная точка на фазу: фаза 1 — правило ADR-01 п.4b; фаза 2 — §10 и
  «B2 бьёт B1». Остальное — описательное.
- **Отбор только внутри training.** Спецификации B0, B1, B1_no_deciles, B2 (ADR-10) и
  перечень наблюдателей фазы 3 замораживаются до открытия любого OOS. Гиперпараметры
  выбираются во внутренних фолдах training. OOS — только подтверждение.
- B2 фиксируется **до** открытия OOS фазы 1; изменение B2 после этого — новая
  предрегистрация, и её OOS не считается независимой проверкой.

## 5. Walk-forward

Фолд = маркетинговый год Sep–Aug; cutoff — 1 сентября 00:00 America/Chicago (в UTC);
переобучение раз на cutoff; общий причинный cutoff для всех культур (метка допускается,
только если сессия `t+H` и публикация settlement ≤ cutoff); расширяющееся окно; burn-in
≥ 10 маркетинговых лет с пригодными PIT-признаками.

**Внутренние фолды — прямые (forward-chaining):** последние `min(5, n_train − 5)`
training-лет по очереди служат валидацией, обучение — на годах строго раньше
(изменение относительно v1.0, где предлагался leave-one-year-out).

## 6. Полужизнь дисконтирования

Вес года `a` при cutoff `T`: `λ^{(T−a)}`, `λ = 2^{−1/h}`, `h ∈ {2, 4, 8, 16, ∞}` лет.
B1 — выбор по внутрифолдовому log score события E; B2 — по внутрифолдовому CRPS
(ADR-10 п.7; приор на `log h` из v1.0 отменён, т.к. взвешенное правдоподобие с весами,
зависящими от параметра, некорректно). В B1 веса дробные → степенное правдоподобие.

## 7. Правило фазы 1 и вероятность достижения фазы 2

Совместная вероятность «фаза 1 пройдена и §10 пройден» внутри DGP — в
`simstudy-summary.md` (раздел «Правило фазы 1»); выводы — в spec-audit.md §3 (вопрос 1)
и ADR-11.

## 8. Воспроизводимость

Зарегистрированное окружение: Linux x86_64, CPython 3.11.x, зависимости по
`requirements.lock`, NumPy/SciPy на CPU (JAX/NumPyro — с фазы 2, настройки потоков
фиксируются тогда). Seeds — в конфигурации; seed ячейки исследования задаётся её
индексом в полной сетке, поэтому любая подсетка воспроизводима отдельно. Побитовая
повторяемость исследования проверена двумя независимыми полными прогонами в этом
окружении (`reproducibility/`); на другом CPU/BLAS побитовое совпадение не обещается.
