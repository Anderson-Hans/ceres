# ADR-09. Определение признака запасов для B1 и базовых трансформаций

**Статус:** Proposed
**Версия:** 1.1 (2026-09-27)
**История:** 1.0 — первичная версия (commit 9d4ebc2). 1.1 — по рецензии §4: 10 децилей сохраняются; укрупнение только отдельным ADR до OOS; ссылка на training-only анализ наполненности (ADR-01 п.4).
**Затрагивает:** §3 (B1), §5.5, §7.1, §9 (фаза 0) спецификации v0.2
**Тип:** [ADR]

## Контекст

- §3: B1 условен на «дециль отклонения запасов от 5-летнего среднего».
- §7.1: «stocks-to-use ratio вместо абсолютных запасов».
- Эти формулировки не совпадают; кроме того, не определено, запасы
  какого маркетингового года, в каком vintage, и что такое «5-летнее
  среднее» по PIT.

## Решение (предлагаемое)

### 1. Базовая величина

`SU(c, m, v)` — US ending stocks / total use для культуры `c` и
маркетингового года `m` по данным WASDE в vintage `v` (первая
публикация или ревизия, видимая в срезе).

### 2. Признак B1

`x(c, t) = SU(c, m*(t), v_t) − mean_{j=1..5} SU(c, m*(t) − j, v_t)`,

где `v_t` — последний WASDE с `vintage_time ≤ as_of_t` (все шесть
значений — **из одного и того же доступного на `t` vintage**, т.е.
«5-летнее среднее» — это среднее оценок прошлых лет, как они были
известны на `t`, а не финальные пересмотренные значения).

`m*(t)` — маркетинговый год, который торгует контракт:
- ZCZ Y, ZSX Y — новый урожай MY `Y/Y+1`; ZWN Y — MY `Y/Y+1`;
- если WASDE в `v_t` ещё не содержит проекции `m*(t)` (до майского
  отчёта года `Y`), используется последний MY, для которого проекция
  есть (`m*(t) − 1`, «старый урожай»), и признак помечается
  `crop_basis = old_crop`. Для B1 децили и счётчики ведутся **раздельно**
  для `new_crop` и `old_crop` только при достаточном числе training-лет;
  иначе — общие (правило фиксируется здесь: раздельно, если в каждой
  группе ≥ 10 training-лет).

### 3. Децили

Границы — квантили `x` по training-выборке, по одной точке на каждый
**релиз WASDE** (не по дням, чтобы дни с одним значением не
взвешивались как отдельные наблюдения), раздельно по культуре.
Границы пересчитываются на каждом cutoff (ADR-05). Для первых 5 лет
истории (нет 5 предыдущих MY) признак не определён → строки не
участвуют в B1 (раскрывается); это не пустой дециль.

### 4. Прочие трансформации фазы 0

- Лог-доходность — ADR-02.
- Сезонное выравнивание — ADR-06.
- Отклонение урожайности от тренда — **не вычисляется в фазе 0–1**:
  тренд должен оцениваться только на training и нигде в B1 не
  используется; определение — при регистрации признаков B2.
- `usda_grain_stocks`: stocks-to-use по квартальным фактическим
  запасам — вычисляется только при регистрации для B2.

### 5. Число групп (решение по рецензии §4)

Для текущей основной гипотезы — **10 децилей** (v0.2). При малом числе training-лет
децили содержат мало независимых эпизодов (spec-audit R-04); это не исправляется
увеличением числа дневных строк. Порядок действий — ADR-01 п.4: training-only анализ
наполненности до OOS; при нехватке — отдельный ADR с предложением укрупнения,
решение принимает аудитор.
