# ADR-04. Наблюдатели, данные для маркеров и распределение по фазам

**Статус:** Proposed
**Дата:** 2026-09-27
**Затрагивает:** §2.1, §3, §5.3, §6.3, §8, §9, §14 спецификации v0.2
**Тип:** [ADR]

## Контекст

- §9, фаза 0: «3 бесплатных USDA-наблюдателя» — без названий; в §5.3
  перечислены четыре USDA-наблюдателя.
- §9, фаза 3: «NOAA, COT» — `usda_export_sales` не распределён ни в одну фазу.
- Имплицитная плотность опционов: §2.1 — «нужна для фазы 4»; §3 (B5),
  §6.3, §9, §14 — фаза 5.
- Маркер концентрации OI: §6.3 и §14 — фаза 3 на бесплатных данных CME.
- Маркеры §8 требуют соседних контрактных месяцев, истории OI,
  spot/basis — минимальная закупка EOD (§6.2) их не гарантирует.

## Решение (предлагаемое)

### 1. Наблюдатели фазы 0

`usda_wasde`, `usda_crop_progress`, `usda_grain_stocks`.

Роли (для трассировки; допуск в модель — только через предрегистрацию):
- `usda_wasde` — признак B1 (stocks-to-use, ADR-09); обязателен с фазы 1.
- `usda_grain_stocks` — квартальные фактические запасы; кандидат для
  B2 (регистрируется до OOS фазы 2 или не используется в фазе 2).
- `usda_crop_progress` — в B1/B2 **роли не имеет**; собирается в фазе 0,
  потому что §9 требует три USDA-наблюдателя, а PIT-архив нужно
  собрать заранее. Кандидат для абляции фазы 3 только если внесён в
  список абляций до экспериментов (см. п. 2). Аудитору: см. spec-audit.md,
  вопрос 9 (кандидат на удаление).

### 2. Наблюдатели фазы 3 и порядок абляций (фиксируется до экспериментов)

1. `noaa_weather` (§9)
2. `cftc_cot` (§9)
3. `usda_export_sales` — **назначение фазы 3 — дополнение промпта**,
   не требование v0.2.

Каждый — «предыдущая принятая модель → один новый наблюдатель →
walk-forward → прирост → retain/reject». Конкретные признаки каждого
наблюдателя регистрируются в `docs/preregistration.md` **до** начала
фазы 3 (сейчас — `pending`, см. open items); регистрация признаков
фазы 3 после просмотра результатов фазы 2 допускается только в
пределах этого перечня наблюдателей (§10: «список наблюдателей фазы 3
фиксируется заранее»).

### 3. Опционы

Согласование: следуем §9 и §14 — **восстановление имплицитной
плотности (Breeden–Litzenberger) — фаза 5**, несмотря на упоминание
фазы 4 в §2.1. Маркер концентрации OI на бесплатных данных CME — фаза 3.

### 4. Данные для рыночных маркеров §8 (проверить в фазе 0, не предполагать)

| Индикатор | Требуемые данные | Покрывается минимальной закупкой §6.2? | Статус |
|---|---|---|---|
| Расхождение ног календарного спреда | EOD settlement соседних контрактных месяцев (не только Z/X/N) | Только если закупка включает все месяцы — **уточнить при закупке** | UNVERIFIED |
| Концентрация OI по контракту | OI по всем контрактным месяцам, PIT | Частично (OI по контрактам в EOD) | UNVERIFIED |
| Концентрация OI по страйкам | История OI опционов по страйкам | **Нет.** Бесплатная страница CME показывает текущее состояние; исторические снимки не доказаны | BLOCKED_DATA для истории; начать архивирование снимков в фазе 0/3 |
| Отрыв фьючерса от базиса сверх модели транспорта/хранения | Spot/cash-цены, базис элеваторов, ставки фрахта/хранения, ставка финансирования — PIT | **Нет** | BLOCKED_DATA; методика не определена |

Отсутствующий маркер не заменяется `severity = "none"` — используется
статус `NOT_EVALUATED` (ADR-03).

### 5. Вопрос аудитору

Индикатор базиса требует данных и модели, которых в проекте нет, и
несёт высокий риск ложных срабатываний на нормальной структуре рынка
(spec-audit.md, вопрос 7). Рекомендация: исключить его из v1 до
появления достоверных входов (решение аудитора/владельца — §8 v0.2
его перечисляет).
