# CERES — шаблон передачи результата на аудит
Версия: 1.0

Заполняет исполнитель после предпроектного аудита и каждой фазы.
Пустое поле не означает PASS. Для неприменимого — NOT_APPLICABLE
с объяснением. Для незапущенного — NOT_RUN.

**Итог исполнителя:** READY_FOR_REVIEW / BLOCKED_DATA / STOP_SCIENCE /
DEFERRED_BUDGET / CHANGES_REQUIRED.

**Следующая фаза:** запрещена до явной приёмки / запрещена научным
стоп-критерием / ожидает данных или бюджета.

Не заполнять APPROVED от лица независимого аудитора.

## 4. Данные и PIT

Указать источники, лицензии, инструменты/контрактные месяцы,
глубину EOD, глубину доказанных vintages и пригодную выборку по годам.

Для каждого источника описать event_time, vintage_time, revised/retrieved
timestamps, единицы, ключ версии, raw hash, парсер и правила freshness.

Раскрыть:
- неархивированные/неизвестные vintages;
- отсутствующие контрактные месяцы и периоды;
- доступность данных о ценовых лимитах;
- источник basis/спредов/OI для маркеров;
- расхождение между объёмом закупленной и реально пригодной истории;
- ограничения передачи данных аудитору.

Приложить dataset manifest и отчёт с двумя обязательными PIT-кейсами:
будущая ревизия не видна; публикация позже as_of в тот же день не видна.
Приложить проверку отсутствия будущих целевых цен в training.

## 7. Диагностика, отказы и маркеры

Указать r_hat, n_eff и область применимости MCMC-диагностики.
Приложить posterior predictive checks, отчёт о проблемных цепях
и поведение при провале.

Показать ABSTAIN по всем причинам, доступность обязательных источников,
невычисленные маркеры и ошибки данных.
NOT_EVALUATED не считать отсутствием аномалии.

Для фазы 3: полная таблица абляций, включая отвергнутые наблюдатели.
Для фазы 4: отдельные выводы 4A/4B/4C.
Для фазы 5: отдельные real-world и risk-neutral распределения.

## 8. Воспроизводимость

Приложить команды установки/запуска, lock-file, runtime, устройство,
backend, число потоков, seeds, resolved config и hashes.
Описать повторный запуск и какие результаты совпали побитово.
Операционные timestamps отделять от детерминированного содержания.

Недоступные аудитору проверки перечислить явно:
нет ключа / лицензии / raw-данных / нужного backend / иная причина.
