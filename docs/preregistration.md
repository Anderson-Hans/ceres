## 2. Предлагаемые формализации (требуют принятия ADR)

### 2.1 Инструменты и веса (ADR-05 п.1, п.3)
ZC (Z) 0.5, ZS (X) 0.5, ZW (N) 0 в гейте; ZW без SIGNAL, индикатор режима с 2022-02-24.
Горизонты 0.5 / 0.5; внутри ячейки — равный вес на пригодную дату.

### 2.2 Target (ADR-02, ADR-06)
`R(t,H) = log(S_obs(c,t+H)/S_obs(c,t))`; окно пригодности до FND−1; `as_of` = 18:00
America/Chicago; scoring по наблюдаемому settlement.

### 2.3 Модели
- **B0** (ADR-01): медиана-центрированное сезонное эмпирическое распределение, окно ±10
  сессий (чувствительность 5/15). Раскрываются B0-CLIM и B0-RW.
- **B1** (ADR-01, ADR-09): событие `E = 1[d·R > 0]`; **10 децилей** признака `x`;
  Beta(1,1) (чувствительность 0.5/2); вес строки 1/H; полужизнь из сетки
  `{2,4,8,16,∞}` по прямым внутренним фолдам; оболочка распределения доходности.
  Альтернатива весов «1 на эпизод» — ADR-11 (решение аудитора; до решения не применяется).
- **B1_no_deciles** (ADR-01 п.4a): B1 без децилей; всё остальное идентично.
- **B2** (ADR-10, `configs/model-b2.yaml`): отдельная модель на каждый H; Student-t;
  среднее `a_c + a_{c,y} + b_c·x̃ + g_c·m̃ + q_c·x̃·m̃ (+ ZW·post·δ_a)`; лог-масштаб
  `ς_c + ς_{c,y} (+ ZW·post·δ_ς)`; частичный пулинг по культурам и годам; приоры —
  таблица ADR-10 п.4; новый год — предиктивный эффект; цензурирование конечной точки;
  композитное правдоподобие с весом 1/H; полужизнь по сетке во внутренних фолдах;
  NUTS 4×1000 после 1000 warmup.

### 2.4 Гейты
- **Фаза 1** (ADR-01 п.4b): `Brier_E(B1) < Brier_E(B0)` и `Brier_E(B1) < Brier_E(B1_no_deciles)`
  на одной выборке (ZC+ZS, оба H, веса §2.1); без барьера значимости; разности и
  двусторонние 95% ДИ (метод §2.5) публикуются.
- **Фаза 2:** B2 бьёт оболочку B1 по CRPS на тех же целях; калибровка/coverage (ADR-03);
  MCMC `r_hat < 1.01`, ESS ≥ 400 (предложение), 0 divergences;
  **§10:** `skill_CRPS = 1 − Σw·CRPS(B2)/Σw·CRPS(B0)`, `lower(two_sided_CI_95) > 0`.

### 2.5 Доверительный интервал (ADR-05 п.2)
Основной: **JK2** — delete-one-block jackknife по парам соседних блоков Sep–Aug,
`t(k₂−1)`, центрирование в `θ̂`, отношение пересчитывается целиком, ledger без
переобучения. Чувствительности: JK (одиночные годы), PB (перцентильный, 10 000
переоценок), влиятельные годы. При `k < 10` — `NOT_EVALUABLE`. Выбор основан на
критериях допустимости, зарегистрированных до симуляционного исследования.

### 2.6 Отбор и подтверждение (ADR-05 п.4–5)
Отбор гиперпараметров — только во внутренних прямых фолдах training. OOS — только
подтверждение. B2 замораживается до открытия OOS фазы 1.

### 2.7 Чувствительности (описательные, не гейт)
B0 окно ±5/±15; B0-CLIM, B0-RW; B1 приор 0.5/2; история с 2007/08 MY; B2 без ZW; B2 на
неперекрывающихся метках; B2 приоры τ ×2; обучение без меток с лимитной конечной точкой;
JK, PB; метрики только на SIGNAL-днях.

### 2.8 Фаза 3
Порядок абляций: `noaa_weather → cftc_cot → usda_export_sales`; признаки — регистрация до
фазы 3. Маркеры: календарь, погода, режим, календарный спред, концентрация OI, базис
(сохранён; `NOT_EVALUATED` без входов).

### 2.9 До открытия OOS (обязательные шаги на training)
1. Training-only анализ наполненности децилей (ADR-01 п.4) → запись в CHANGELOG.
2. Оценка межгодовой дисперсии CRPS-разности вариантов B0 на training.
3. Подсчёт числа честных OOS-блоков; если < 10 — §10 заранее `NOT_EVALUABLE`.
