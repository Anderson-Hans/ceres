## 2. Предлагаемые формализации (требуют принятия ADR)

### 2.1 Инструменты и веса (ADR-05)
ZC (Z) — 0.5, ZS (X) — 0.5, ZW (N) — 0 в гейте; ZW без SIGNAL, режимный флаг с 2022-02-24.

### 2.2 Target (ADR-02, ADR-06)
`R(t,H) = log(S_obs(c,t+H)/S_obs(c,t))`, daily settlement одного контракта; окно
пригодности до FND−1; срез `as_of` = 18:00 America/Chicago; scoring всегда по
наблюдаемому settlement.

### 2.3 Модели
- **B0** (ADR-01): медиана-центрированное сезонное эмпирическое распределение, окно
  ±10 сессий (чувствительность 5/15). Раскрываются B0-CLIM и B0-RW (63 сессии).
- **B1** (ADR-01, ADR-09): событие `E = 1[d·R > 0]`; Beta(1,1) (чувствительность
  0.5/2); группы культура × горизонт × дециль `x`; веса 1/H и дисконтирование
  `h ∈ {2,4,8,16,∞}` по внутренним фолдам; оболочка распределения доходности; B1-pooled —
  обязательная диагностика.
- **B2** — **не специфицирована** (OI-02). Должна быть заморожена до открытия OOS
  фазы 1: иерархия (культура, год), правдоподобие, ковариаты, приоры и их диапазоны,
  цензурирование конечных точек, `log h ~ N(log 8, 1)`, NUTS 4 цепи.

### 2.4 Гейты
- Фаза 1: `Brier_E(B1) < Brier_E(B0)`; раскрываются разница, блочный ДИ, число блоков.
  Рекомендуется (OI-06) также `Brier_E(B1) < Brier_E(B1-pooled)`.
- Фаза 2: B2 бьёт оболочку B1 по CRPS на тех же целях; калибровка/coverage по ADR-03;
  MCMC `r_hat < 1.01`, ESS ≥ 400 (предложение), 0 divergences;
  **§10:** `skill_CRPS = 1 − Σw·CRPS(B2)/Σw·CRPS(B0)`, `lower(CI95) > 0`,
  ДИ — jackknife-t по маркетинговым годам (OI-05), перцентильный блочный — раскрывается.

### 2.5 Отбор и подтверждение (ADR-05)
Отбор гиперпараметров — только во внутренних фолдах training (leave-one-training-year-out).
OOS — только подтверждение одной зарегистрированной спецификации на фазу. B2
замораживается до открытия OOS фазы 1.

### 2.6 Чувствительности (описательные, не гейт)
- B0 окно ±5/±15; B0-CLIM, B0-RW;
- B1 приор 0.5/2; децили vs B1-pooled;
- история с 2007/08 MY (этаноловый мандат, §7.1);
- B2 без ZW в иерархии;
- обучение B0/B1 без меток с лимитной конечной точкой;
- блоки по 63 сессии для ДИ;
- метрики только на SIGNAL-днях (дополнительный срез).

### 2.7 Фаза 3
Порядок абляций: `noaa_weather → cftc_cot → usda_export_sales`. Признаки — регистрируются
до фазы 3 (OI-03).

## 3. Минимально обнаружимый эффект (к сведению до OOS)

Синтетическая симуляция (верхняя граница мощности): при 15 OOS-годах вероятность
пройти §10 jackknife-t — 0.15 / 0.29 / 0.39 / 0.61 при истинном skill 0.01 / 0.02 /
0.03 / 0.05. Закрытие проекта по §10 при ≤ 20 OOS-годах следует интерпретировать как
«эффект не обнаружим данной схемой», а не как доказательство его отсутствия.
